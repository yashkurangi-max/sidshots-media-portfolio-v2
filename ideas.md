# Jasper Hale Photography — Design Direction

## Three stylistic approaches

### Theme Name: Sunlit Contact Sheet
Very Brief Intro: A tactile editorial portfolio that feels like a working photographer's desk: contact sheets, handwritten-style annotations, and gallery frames warmed by natural light.
Probability: 0.07

### Theme Name: Soft Signal Studio
Very Brief Intro: A quiet, airy studio system with pastel green, butter yellow, and measured typography. The interface behaves like a calm art-direction dashboard rather than a generic portfolio grid.
Probability: 0.05

### Theme Name: Mineral Afterimage
Very Brief Intro: A darker, gallery-like direction using mineral tones, luminous image edges, and slow optical movement to make each project feel like a collected artifact.
Probability: 0.08

## Chosen approach: Soft Signal Studio

### Design Movement
Contemporary editorial modernism with references to Swiss photo books, art-direction workboards, and the tactile calm of a daylight studio.

### Core Principles
1. **Image-first asymmetry:** the page should feel composed around photographs, not around a symmetrical web template.
2. **Quiet instrumentation:** metadata, indices, progress bars, and category labels make the portfolio feel like a working studio dashboard.
3. **Pastel contrast:** moss green carries trust and craft while warm yellow introduces light, optimism, and a recognizable signature.
4. **Soft tactility:** grain, paper-like surfaces, hairline rules, and controlled blur make the digital page feel printed and physical.

### Color Philosophy
Pastel green is the base atmosphere: grounded, calm, and connected to daylight. Warm yellow is used as an intentional flash of light for active states, editorial notes, and booking moments. Ink-black text keeps the palette legible and prevents the softness from becoming vague.

### Layout Paradigm
An asymmetric editorial canvas with a left rail for navigation and project metadata, a wide image field for the portfolio, and dashboard cards that read like studio instruments. The gallery uses a masonry rhythm instead of equal tiles.

### Signature Elements
- A small aperture-leaf mark that appears in the header, hero framing, and footer.
- A floating “current focus” card that tracks the active body of work with a scanline-like progress indicator.
- Pill-shaped filter controls paired with compact monospaced metadata labels.

### Interaction Philosophy
Interactions should feel like turning a printed contact sheet: quick, tactile, and informative. Hovering reveals project context without hiding the image, filters shift the gallery immediately, and calls to action use a short press response rather than oversized motion.

### Animation
The background uses slow, low-contrast orbital blobs to suggest light moving across a studio wall. Gallery images lift by a few pixels on hover and reveal a soft caption wash. Entrances are staggered only where it helps scanning; all essential motion is disabled for reduced-motion preferences.

### Typography System
Display headlines use **Playfair Display** in a slightly tight, confident serif treatment. Interface labels and body copy use **DM Sans** for warmth and clarity. **Space Mono** is reserved for indices, metadata, and small dashboard readouts.

### Brand Essence
Jasper Hale makes commercially useful images feel editorial, for brands that need people, products, and places to look considered without looking over-produced. Personality: **observant, warm, precise**.

### Brand Voice
Headlines are concise and image-led. CTAs sound like an invitation from a working studio, never a sales funnel.

Example lines:
- “Make the useful look unforgettable.”
- “Bring the brief. I’ll bring the light.”

### Wordmark & Logo
The mark is a six-blade aperture merged with a single rising leaf: a symbol of looking closely while keeping the work alive and human. The wordmark is set separately in an editorial serif and is never treated as a default text logo.

### Signature Brand Color
**Signal Moss — #6E9D73**, a softened moss green that feels distinctive on cream paper and stays legible beside warm yellow.

## Reference Ground-Truth Spec — Attached Spoils Trophy Video

The attached video supersedes the previous pastel direction for the visual treatment. The portfolio should now use a strict black-and-white editorial system where the photographs provide the only color. The structure is a long-scroll archive with a sticky minimalist header, a centered wordmark, compact navigation, and a high-contrast action button.

The hero should feel like a photo competition or printed contact sheet: oversized serif branding, small uppercase metadata, a dense row of varied image frames, thin gutters, visible print borders, and subtle rotation. Gallery work should use grayscale imagery, crisp card edges, hover reveals, and a masonry rhythm. A black studio section, film-strip ticker, grain, light leaks, and restrained slide-up reveals should create analog motion without overwhelming the photography. Mobile layouts should collapse into a single-column archive while preserving prominent type and generous image frames.
